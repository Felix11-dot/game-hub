# 🎮 Game Hub

A simple collection of browser games. Pick a game and play with friends.

## ▶️ Play now (no download needed)

**https://felix11-dot.github.io/game-hub/**

Just open the link in your browser. It works on phones, tablets and laptops, with no install and no account.

## Games

- **24 Game**: use four cards to make exactly 24 (1–6 players, Easy and Hard modes)

## How to play 24 Game

1. Choose the number of players.
2. Use all four cards once each with `+ − × ÷` and parentheses to make 24.
3. Example: 6, 2, 5, 2 → `(6 + 2) × (5 − 2) = 24`
4. The first player to get 24 taps their name to score a point.
